# AIR · ATS design system

AIR is an applicant tracking system for recruiting teams. Its AI drafts and cites; people decide.
This Storybook is AIR's design system in code: the same tokens and components as the Figma library, built in React and TypeScript.

## How it's made

1. **Figma is the source.** Colours, spacing, radius, type and effects live as Figma variables and styles, each with a CSS name such as `--air-action-primary`.
2. **Tokens are exported, not retyped.** `tokens/figma-export.js` runs inside the Figma file and writes `src/tokens/tokens.css`. The Foundations pages here read that file, so they always show what Figma holds.
3. **Components map one to one.** Each component follows its Figma component set: the same properties, states and token names.

## Principles

- **Light first.** Dark values are in the tokens; screens ship light.
- **AI is violet, and only for AI.** Anything the AI made, suggested or filled carries the AI tone.
- **Focus is always visible.** Keyboard focus shows a 2 px ring with a 2 px gap on every control.
- **Accessible by default.** Text contrast of at least 4.5:1, 3:1 for icons and focus rings; every story runs an accessibility check.

## Status

Foundations and 22 components, grouped as in the sidebar: Actions, Forms, Navigation, Feedback and Data display. Each story has the component's states from Figma, and every story runs an accessibility check. AIR's own components (stage path, match grade, evidence rows, candidate card) come next.
