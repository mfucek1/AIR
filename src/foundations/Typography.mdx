# Typography

One family, Inter, in 13 styles. Each style is a `font` shorthand plus a tracking value:

```css
font: var(--air-font-body-m);
letter-spacing: var(--air-tracking-body-m);
```

Rules: sentence case for labels, 12 px minimum, and tabular figures in tables and KPIs (`font-variant-numeric: tabular-nums`).
