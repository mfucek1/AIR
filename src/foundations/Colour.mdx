# Colour

Two layers. **Primitives** are the raw ramps. **Roles** name a job, like `--air-action-primary`, and point to a primitive. Components only use roles, so a theme change happens in one place.

- **Petrol** is the brand and the action colour.
- **Apricot** is the accent, used sparingly.
- **Violet** is reserved for AI.
- **Slate** neutrals carry a little petrol, so greys sit well next to the brand.
